# InteractiveScene (Интерактивная модель)

# Управление
- ПКМ (зажать) - движение (верх, вниз, вправо, влево)
- СКМ (зажать при выбранном объекте) - врщение вокруг объекта
- Колёсико вверх/вниз (при выбранном объекте) - приближение отдаление на заданное расстояние
- Ctrl+S - сохранить объекты
- Alt+S - загрузить объекты

## Верхняя
Позволяет:
- выделить все объекты
- изменить прозрачность выделенных объектов
- скрыть/показать выделенные объекты
## Нижняя
Отображает объекты, содержащие SceneObjectController.
Каждый элемент списка содержит:
- название объекта
- кнопки изменения цвета
- checkbox состояния выбора объекта



# Технологии
